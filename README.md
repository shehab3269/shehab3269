> *"I build things that make people's lives easier, one pixel and one line of code at a time."*

I'm a **Flutter Mobile Developer** focused on crafting clean, performant, cross-platform apps with **Dart**. I care about good **architecture**, smooth **user experience**, and code that's pleasant to read.

- 🎯 **Flutter & Dart** — my core focus, building production-ready mobile apps
